# Потоковые месячные артефакты v2

## Форматы

`monthly-fact-v2` хранит компактные `manifest.json` и `summary.json`; полные РО находятся только в
`day=YYYY-MM-DD.json`. Manifest фиксирует входную сигнатуру, digest, статус и агрегаты каждого дня.
`monthly-placement-only-v2` использует такую же схему для сравнений: месячный `comparison.json`
содержит агрегаты, покрытие, предупреждения, вклад SKU/зоны/ряда и ссылки на дневную детализацию.

`monthly-fact-v1` и `monthly-placement-only-v1` считаются legacy read-only: компактный summary
читается без запуска расчёта, а запрошенный дневной файл можно открыть отдельно. Неизвестная версия
получает `unsupported_artifact_format`.

## Остановка и продолжение

Дневной файл сначала записывается во временный файл в целевом каталоге и публикуется через
`os.replace`; только затем атомарно обновляется manifest. При новом запуске checkpoint принимается,
только если совпадают версия, входная сигнатура, дата и SHA-256 содержимого. Поэтому завершённые дни
пропускаются, повреждённый день пересчитывается, а изменение данных, геометрии, правил или routing
создаёт независимый набор checkpoint. Summary публикуется после завершения всех дней.

Память расчёта содержит маршруты только текущего операционного дня. UI читает компактный manifest и
загружает полный дневной FACT либо comparison только после выбора детализации.
