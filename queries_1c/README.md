# Запросы 1С

Каталог содержит только готовые запросы для ручного запуска в консоли запросов 1С.
Приложение читает файлы как текст: они не выполняются автоматически и не меняют импорт
Excel, парсеры, расчёты, маршрутизацию или остатки.

## Массовая выгрузка расходных ордеров

Файл `mass_outbound_orders.query` выгружает товарные строки расходных ордеров за период
по одному складу. Перед выполнением задайте параметры `НачалоПериода`, `КонецПериода`,
`Склад` и `ТолькоПроведенные`.
